Sistema de Gestión de Tareas

Proyecto desarrollado con Python, Flask y SQLite.

Funcionalidades

  • Registro de usuarios.
  • Inicio de sesión.
  • Almacenamiento de contraseñas mediante hash.
  • Base de datos SQLite.
  • Endpoint GET /tareas.
